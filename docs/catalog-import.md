# Импорт каталога и форм

`scripts/build_seed.py` читает `Датасеты_хакатон.xlsx` и `catalog_export_v4.csv`.

- заголовки разделов XLSX становятся группами формы;
- тип значения определяется по базовому значению;
- диапазоны чисел сохраняются для серверной и браузерной валидации;
- ключевым показателям назначаются стабильные коды расчётного ядра;
- остальные коды формируются детерминированно;
- одинаковый `id` CSV создаёт один `RobotSolution`, каждая строка с кейсом — отдельный `DeploymentCase`;
- грузоподъёмность извлекается только из явной фразы в названии; при её отсутствии хранится `null`.

Полный OCR большого PDF сознательно не включён: извлечение текста повреждает часть кириллицы, а CSV уже предоставляет структурированный конкурсный слой.
