# Развёртывание

Локальный стенд запускается `docker compose up --build`. Для внешнего размещения обязательно:

- заменить все значения `.env`, включить HTTPS и ограничить CORS;
- хранить секреты в секрет-хранилище, а не в compose-файле;
- добавить резервное копирование PostgreSQL;
- заменить in-memory rate limiter общим хранилищем;
- настроить наблюдаемость и политику хранения audit events;
- не включать `input/` и пользовательские файлы в образ.

Frontend отдаётся Nginx на порту 3000, backend — 8000, PostgreSQL наружу не публикуется.
