# Ограничения и дорожная карта

Текущий продукт — предварительная оценка, не цифровой двойник и не замена обследованию.

Главные ограничения:

- конкурсный CSV почти не содержит технических характеристик;
- proxy-оценки производительности и инфраструктуры помечены допущениями;
- данные XLSX — демонстрационные бенчмарки, а не параметры реального заказчика;
- 2D-маршрут выбирается из двух ортогональных вариантов и не моделирует очереди, диспетчеризацию и зарядные события;
- rate limit локален одному процессу;
- UI администратора и пользовательский импорт ещё не реализованы;
- текст большого PDF частично повреждается при извлечении, поэтому импортировано структурированное подмножество;
- распознавание чертежей не реализовано и не должно обещаться пользователю как готовое.

PDF/CSV и P0 2D теперь реализованы. Следующие шаги по ценности: preview/mapping пользовательского импорта; визуальный admin CRUD; паспорта подтверждённых ТТХ; A*/граф видимости и дискретные события; затем vector-first/OCR `DraftPlan`.

Любая смена формулы экономики, парка или симуляции требует новой версии и теста воспроизводимости. Неизвестное значение остаётся `unknown`/`null` и не считается пройденным ограничением.
