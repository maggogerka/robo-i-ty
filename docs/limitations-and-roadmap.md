# Ограничения и дорожная карта

Текущий продукт — предварительная оценка, не цифровой двойник и не замена обследованию.

Главные ограничения:

- конкурсный CSV почти не содержит технических характеристик;
- proxy-оценки производительности и инфраструктуры помечены допущениями;
- данные XLSX — демонстрационные бенчмарки, а не параметры реального заказчика;
- rate limit локален одному процессу;
- UI администратора, импорт пользователя, 2D и PDF/CSV ещё не реализованы;
- текст большого PDF частично повреждается при извлечении, поэтому импортировано структурированное подмножество.

Следующие шаги по ценности: 2D throughput simulation; PDF/CSV; preview/mapping импорта; визуальный admin CRUD; подтверждённые паспорта ТТХ минимум для 10 складских продуктов.
