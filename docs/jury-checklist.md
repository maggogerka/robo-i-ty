# Чек-лист демонстрации жюри

- [x] Русский интерфейс и понятный маршрут из шести шагов.
- [x] Параметры трёх типов объектов строятся из метаданных.
- [x] 187 семейств и 190 конфигураций каталога; конфликтующие ID не затираются.
- [x] Неизвестные ТТХ остаются `null`/`unknown`.
- [x] Безопасная загрузка чертежа и изоляция файлов по владельцу.
- [x] Ручная калибровка масштаба по двум точкам.
- [x] Редактор стен, дверей, стеллажей, препятствий, зон и контрольных точек.
- [x] Confidence, ручная проверка, undo/redo и история версий плана.
- [x] Demo-распознавание явно помечено как шаблон, а не нейросеть.
- [x] Опциональный локальный Yytsi-провайдер не имеет доступа к внешним URL.
- [x] Подбор объясняет ограничения и вклад весов 25/25/20/15/10/5.
- [x] A* учитывает габарит и не выдаёт непроходимый маршрут за успешный.
- [x] База, покупка и RaaS сравниваются одной версией экономики.
- [x] PDF/CSV содержат единицы, источники, статусы и ограничения.
- [x] Проекты и файлы изолированы по владельцу; admin проверяется сервером.
- [x] `input/`, `.env`, `storage/`, PDF и пользовательские выгрузки игнорируются git.
- [x] Backend/frontend проверки и production build проходят.

Перед показом: `docker compose up --build`, открыть `/demo`, пройти все шесть шагов и заранее проверить PDF-шрифт на целевой машине.
