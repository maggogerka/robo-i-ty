# Контракт распознавания плана (планируется)

Будущий `PlanRecognitionProvider` возвращает не рабочий `Plan`, а проверяемый `DraftPlan`: hash источника, страницы, масштаб и доказательства масштаба, стены, препятствия, зоны, двери, маршруты, зарядные точки, confidence, source region, метод извлечения и unresolved elements.

Планируемые реализации:

- `ManualPlanProvider` — текущий ручной React Konva-редактор;
- `DemoPlanProvider` — текущий детерминированный демо-план;
- `LocalVisionProvider` — выключенный feature flag до безопасной загрузки, golden set и измеримых метрик.

Обязательные правила:

1. Неизвестный масштаб остаётся `unknown` и блокирует метрическую симуляцию.
2. Результат модели не сохраняется как рабочий план без подтверждения пользователя.
3. Каждый элемент прослеживается до страницы и bbox исходника.
4. Процесс inference не имеет сети, shell, Docker socket, `.env` и прямого доступа к БД.
5. Версии весов, hash, лицензия и метрики фиксируются в результате.

Подробная архитектура и рекомендуемые локальные модели: [local-vision-model.md](local-vision-model.md).
