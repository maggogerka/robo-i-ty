# Контракт распознавания плана (планируется)

Будущий `PlanRecognitionProvider` возвращает масштаб, стены, препятствия, зоны, двери, маршруты, зарядные точки, confidence и unresolved elements. Любой результат требует подтверждения пользователем.

Планируемые реализации: `ManualPlanProvider`, детерминированный `DemoPlanProvider` и выключенный feature flag для `LocalVisionProvider`. В текущем инкременте провайдеры и загрузка изображений не реализованы.
