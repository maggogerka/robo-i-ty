# Экономическая модель

Все деньги — рубли, горизонт — годы, поток — задания в сутки.

- трудовые затраты базы = целевой персонал × месячная стоимость × коэффициент начислений × 12;
- парк = `ceil(пиковый суточный поток / производительность одного робота за рабочее время)`;
- CAPEX покупки = оборудование + инфраструктура + ПО + интеграция + ПНР + обучение + резерв;
- OPEX = сохранённый персонал + сервис + лицензии + энергия + ремонт + персонал эксплуатации;
- годовой эффект = OPEX базы − OPEX сценария;
- окупаемость = CAPEX / положительный годовой эффект;
- TCO = CAPEX + OPEX × горизонт;
- ROI горизонта = `(затраты базы за горизонт − TCO сценария) / CAPEX сценария × 100%`.

При эффекте ≤ 0 окупаемость равна `null`, а UI показывает «Не окупается». RaaS включает стартовую интеграцию и ежемесячный платёж. Чувствительность пересчитывает цену оборудования, объём операций и стоимость труда при −20%, базе и +20%.

Значения производительности робота, доли автоматизации, сервиса и RaaS — демонстрационные допущения `assumed`; они возвращаются API вместе с результатом.
